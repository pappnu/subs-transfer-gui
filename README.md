# Subs Transfer GUI

A simple graphical user interface for batch transferring subtitles and fonts from a set of Matroska containers to another using Sushi subtitle shifter and MKVToolNix.

## Requirements

- Python
- Node
- mkvextract (accessible via PATH)

## Installation

Install dependencies.

```sh
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

npm install
```

Run the application.

```sh
npm run tauri dev
```
